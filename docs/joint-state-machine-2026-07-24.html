Why there is no free edge back

the trapA state machine where “go back to open” costs nothing is a machine that quietly forgets. A joint under test that turns out to be inconvenient just slides back to open, and the record shows a question that was never actually asked.
the fixunder_test → open demands resolution { outcome: failed_to_run, reason }. Retreating is still allowed — but it has to be written down as a thing that happened, with a reason. The refusal message says so in as many words: a free under_test→open edge does not exist.
the same ideaReopening something already resolved needs shaken_evidence_ref: not an opinion that the answer feels wrong, but a pointer to the evidence that shook it. Dissolution is deliberately its own artifact and is refused if a resolution rides along, because breaking a question into smaller questions is not the same act as answering it.

This is what makes the cycles safe to have. Loops in a state machine are usually where accountability leaks out; here each loop is tolled, so going round costs a record every time.

Cycles are not the weakness of this graph, they are the point — a joint you cannot reopen is a decision you can never be wrong about. What keeps that honest is that every way back charges you an artifact.

This is one of the four modes in LIFECYCLE_MODES, and it is the only one that is not a build lifecycle. It borrows the same guard the feature phases use, so there is a single lifecycle authority rather than two — which is also why its graph picks up resolved → complete and kill edges it can never actually take.
