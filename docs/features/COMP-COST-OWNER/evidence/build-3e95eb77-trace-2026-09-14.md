**2026-09-14.** The surviving finding from the ledger rebuild. Question: are the tokens
inflated, or are the dollars missing?

The build made **three** dispatches. Their per-dispatch sums reconcile **exactly** with the
`build-actuals` row — no inflation, no double count, no retry summing:

**One dispatch is 97.4% of the tokens and carries no dollars at all.** That is the whole
anomaly. `tokens_total` was never inflated, so the S1 accumulator arithmetic is exonerated
again — this is the unpriced-spend family (S1/S2), one layer further out.

## Why that dispatch was unpriced

Traced from the value's set-site outward, not from the shape:

1. **compose recorded what it was given.** `lib/stratum-mcp-client.js:246` writes
   `usd: finiteOrNull(usage.usd)` from the `agent_run` result envelope. The envelope had no
   `usd`, so the row got `null`. compose prices nothing (S3), correctly.
2. **stratum omitted it.** `codexUsageFields` (`ts/src/connectors/codex.ts:603`) emits
   `...(effective > 0 ? { usd: effective } : {})`. **Codex reports no cost of its own** — its
   usage events carry token counts only, and the CLI has no cost tracking — so the accumulated
   `costUsd` stayed `0` and the key was omitted. Omitting is the RIGHT call: it keeps an
   unknown cost unknown instead of stamping a false $0 (the S2 defect).
3. **It was not a stale rate table.** `gpt-5.6-terra` has been in
   `ts/src/judge/pricing.ts` since **`4ac7ad3`, 2026-07-10** — five weeks before this dispatch.
   The rate existed; nothing ever multiplied by it.

## Already fixed upstream, and the fix is live

**stratum `00ff4db` (2026-09-12), "codex must price its own calls; correct stale terra/sol
rates".** `codexUsageFields` now falls back to `usdFromTokens(model, …)` when the connector
reports nothing, labelled `usdSource: "estimated"` — never `reported`, because a consumer may
refuse to reconcile against an estimate. An unpriced MODEL still yields 0 and still omits the
key, so an unknown model stays unknown.

Verified live rather than assumed — compose resolves `@smartmemory/stratum` to the sibling
checkout (0.5.2) and its `dist/connectors/codex.js` carries `usdFromTokens`. Pricing that
dispatch's volume today:

|---|---|
| 400k in / 0 cached / 25,284 out | **$1.1034** |
| 400k in / 380k cached / 25,284 out | **$0.4194** |
| unpriced model | 0 (key still omitted) |

So the build would record roughly **$1.12–$1.81** today instead of $0.6974.

## Correction to my own 0.28x

The "0.28x UNDER" that led here compared **build `3e95eb77` (3 dispatches)** against **flow
`4122e695` (15 dispatches)**. Those are different scopes, so 0.28x overstates the gap. The
under-record is real — 97.4% of the build's tokens carried no price — but the ratio was not
apples to apples, and the flow's other dispatches sit in a different accumulator lifetime
(the `$1.6044701` history row, per 0c).

## Live residue

1. **449,116 of 796,356 tokens (56%) in this project's ledger carry no dollar value.**
   All of it is pre-fix: the unpriced rows with real volume are the two 2026-08-18 terra
   dispatches (425,284 + 23,828). The rest are 2-token fixtures or `outcome: error` rows with
   `tokens_total: null`. **No live leak** — but the historical rows cannot be repriced, for
   the reason below.

2. **compose discards the token split on EVERY stratum-routed dispatch.**
   `lib/stratum-mcp-client.js:240-241` hardcodes `tokens_in: null, tokens_out: null`, while
   the SAME FILE at `:873` reads `value.split` off the same result envelope and prefers it,
   with a comment (`STRAT-USAGE-SPLIT`) saying the legacy reconstruction "cannot tell input
   from output and filed the whole aggregate as output for every record ever written".
   Measured: `tokens_in` is null on 36 of 39 stratum-routed claude rows and on 6 of 6 codex
   rows; the 3 populated ones come from `lib/local-claude-connector.js`, which does read its
   capture. **Consequence:** a ledger row records a total only, so no consumer can reprice it
   — input and output differ by 6x on terra — and the 449k unpriced historical tokens are
   therefore unrecoverable. This is live today.

**Falsifier:** `lib/stratum-mcp-client.js:240-241`. If those two fields are ever sourced from
`resultOrError.split`, this item is closed.

## Method note

Three claims in this trace were checked rather than reasoned from shape, and one of them
inverted an assumption: the rate table was the obvious suspect and was **not** the cause
(terra predates the dispatch by five weeks). The dispatch-level reconciliation — three rows
summing exactly to the terminal row — is what made "inflated tokens" falsifiable in one step.
