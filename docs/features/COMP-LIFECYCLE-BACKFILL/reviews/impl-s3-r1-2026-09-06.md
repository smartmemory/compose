## Controller notes after the fix round (unsandboxed)

The sandbox cannot bind a server, so the route suite had never executed before the controller ran it. Two
defects surfaced only there and were fixed by the controller:

- `readFileSync` was used but never imported in `test/lifecycle-backfill-routes.test.js` (three new tests threw
  `ReferenceError`).
- The file hung after all tests passed: a listening `Server` with zero connections survived. The describe-level
  `beforeEach` also fires for nested `t.test` subtests, so the crash-then-retry test opened three contexts and the
  overwritten ones were never closed; a subtest's teardown was also registered on the PARENT `t.after`, which does
  not run. Fixed by tracking every hook-opened context and closing all in `afterEach`, and by registering subtest
  teardown on the subtest's own context. Diagnosed with `process._getActiveHandles()` after the suite.
