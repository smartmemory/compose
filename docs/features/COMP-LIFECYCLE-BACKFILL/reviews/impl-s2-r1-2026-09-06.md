## Raw findings

1. **P1 — lib/completion-gate.js:991: Lock released before writes finish.** Returning `backfillWriteSequence(...)` without awaiting it runs `finally → release()` at its first suspension. Completion-record, status, audit, and finalization writes run unlocked. A concurrent retry can enter the same pending operation while these writes continue. **Change:** `return await backfillWriteSequence(...)`; verify a second caller remains blocked through finalization and intent clearing.

2. **P1 — lib/completion-gate.js:1259: Default projection is overwritten by finalization.** Without a running server, `defaultVisionProjector` uses `VisionWriter._directCompleteItem`, which updates a separately loaded disk snapshot. The supplied live store still holds `status:'in_progress'` without the projection stamp; step 6.6 serializes that stale item over the successful projection. The operation finalizes and clears its intent with the item incomplete. **Change:** project through `applyVerifiedProjection` on the supplied store; assert build-mode status and stamp from disk after finalization.

3. **P1 — lib/completion-gate.js:1260: Returned projection failures still finalize.** `applyVerifiedProjection` returns `{ok:false}` on verification or persistence failure. This caller only handles exceptions. Probe returned `status:'finalized', partial:false, failures:[]` alongside `visionProjection.ok:false`. **Change:** collect unsuccessful projection results as failures and retain the pending record and intent. Test the production projector's failure result without the test callback's throw adapter.

4. **P2 — lib/completion-gate.js:1264: Persisted guard flag does not reach the default verifier.** The payload includes `guarded`, but `defaultVisionProjector` neither accepts nor forwards it; `VisionWriter` verifies against live configuration. The test at `test/lifecycle-backfill.test.js:612` supplies its own correctly wired callback, bypassing this defect. **Change:** thread both `consultGuard` and `guardEnabledOverride` through the actual default projection path and test both flips there.

5. **P2 — contracts/lifecycle-backfill.schema.json:222: Guarded checksum constraints are unenforced.** Ajv accepts guarded intents with missing `expected_policy_checksum`, differing checksums, and null `policy_checksum`. The "rejected" test expects schema acceptance and checks disagreement using a test-local replica. **Change:** conditionally require non-null checksums for guarded intents; enforce equality through configured cross-field validation. Test the production validator, not a copied predicate.

6. **P2 — lib/completion-gate.js:1325: Failed finalization returns a finalized record.** Rollback restores `snapshot2`, but the response returns the detached `liveRecord` already mutated to `finalized`. **Change:** return the restored record, including its original `finalizedAt`.

7. **P2 — test/lifecycle-backfill.test.js:355: No-spawn marker cannot detect execution attempts.** The marker script has neither executable permissions nor a shebang, so an attempted invocation fails before writing the marker; its absence proves nothing. **Change:** executable script with a Node shebang, positively verified through the same transport before use as the negative assertion.
